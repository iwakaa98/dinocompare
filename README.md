# DentSravni

Сравняване на зъболекарски продукти по **реална стойност** — цена + доставка + хипотетична митница — за да не обикаляте няколко сайта ръчно.

## Какво има

- Търсене по име на продукт и топ 2–3 най-изгодни оферти
- Разбивка: продукт / доставка / митница (0 в ЕС)
- Регистрация и вход
- Меню „Скорошни“ с история на търсенията
- Каталог с най-търсени продукти, кеширан ~7 минути

> Демонстрационните оферти са симулирани върху реалистични доставчици (BG / ЕС / извън ЕС). Готови сте да свържете реални API-та или scrapers по-късно.

## Стартиране

```bash
npm install
npx prisma migrate dev
npm run db:seed
npm run dev
```

Приложението тръгва на [http://127.0.0.1:43127](http://127.0.0.1:43127).

## Стек

- Next.js (App Router) + TypeScript + Tailwind
- NextAuth (credentials)
- Prisma + SQLite
- Zod + bcrypt

## Акаунт

1. Отворете `/register`
2. Създайте акаунт
3. Търсете продукти — появяват се в „Скорошни“
